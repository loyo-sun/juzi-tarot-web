## 🔐 登录

### 访问地址

```
https://你的域名.vercel.app/admin/
```

或

```
https://juzi.loyo.work/admin/
```

### 登录步骤

1. 访问管理后台登录页面
2. 输入管理员邮箱：`qsun@vip.qq.com`
3. 输入密码（Supabase 中设置的密码）
4. 点击"登录"按钮

### 登录状态

- 登录后会自动保存 Token，下次访问无需重新登录
- Token 有效期约 1 小时，过期后需要重新登录
- 点击右上角"退出"可以退出登录

## 📊 统计数据

登录后默认显示统计数据页面。

### 显示内容

#### 主要指标卡片

| 指标 | 说明 |
|------|------|
| 总兑换码 | 系统中创建的兑换码总数 |
| 总占卜次数 | 所有用户完成的占卜总数 |

- **已禁用**：被管理员手动禁用的兑换码
- **使用率**：活跃兑换码占总数的百分比

### 数据刷新

- 切换到其他页面再切换回来即可刷新数据
- 数据为实时查询，准确反映当前状态

## 🎫 生成兑换码

### 访问方式

点击左侧菜单"兑换码管理"。

### 生成步骤

1. **填写生成参数**：
   - **生成数量**：一次生成多少个兑换码（1-100）
   - **问题次数**：每个兑换码可以占卜几次（1-100）
   - **追问次数**：每次占卜可以追问几次（0-10）
   - **有效期(天)**：兑换码的有效期（1-365天）
   - **备注**：可选，用于标记这批兑换码的用途

2. **点击"生成"按钮**

3. **查看生成结果**：
   - 成功后会显示所有生成的兑换码
   - 每个兑换码格式为：`XXXX-XXXX-XXXX`（12位）

4. **复制兑换码**：
   - 点击"复制到剪贴板"按钮
   - 兑换码会以列表形式复制，每行一个

### 兑换码格式说明

- 格式：`XXXX-XXXX-XXXX`
- 示例：`3K8Y-9M2A-7R5N`
- 特点：
  - 使用雪花算法生成，全局唯一
  - 去除易混淆字符（O、I、L）
  - 大写字母和数字组合
  - 随机打乱，无规律

### 推荐配置

| 用途 | 问题次数 | 追问次数 | 有效期 |
|------|----------|----------|--------|
| 普通用户 | 3 | 3 | 30天 |
| VIP 用户 | 10 | 3 | 90天 |
| 测试用户 | 5 | 3 | 7天 |
| 活动赠送 | 1 | 3 | 7天 |

## 📝 管理兑换码

### 查看兑换码列表

在"兑换码管理"页面下方显示所有兑换码。

#### 列表字段说明

| 字段 | 说明 |
|------|------|
| 兑换码 | 完整的兑换码 |
| 次数 | 已用次数/总次数（如：1/3） |
| 状态 | 活跃/已过期/已禁用 |
| 过期时间 | 兑换码的过期日期 |
| 备注 | 创建时添加的备注信息 |
| 操作 | 禁用/启用按钮 |

### 搜索和筛选

1. **搜索框**：
   - 输入兑换码或备注关键词
   - 支持模糊搜索

2. **状态筛选**：
   - 全部状态
   - 活跃
   - 已过期
   - 已禁用

3. **点击"搜索"按钮**查看结果

### 禁用/启用兑换码

**禁用兑换码**：
1. 找到要禁用的兑换码
2. 点击"禁用"按钮
3. 确认操作
4. 兑换码状态变为"已禁用"，用户无法使用

**启用兑换码**：
1. 找到已禁用的兑换码
2. 点击"启用"按钮
3. 确认操作
4. 兑换码状态变为"活跃"，用户可以使用

### 分页

- 每页显示 20 条记录
- 点击"上一页"/"下一页"切换页面
- 显示当前页码和总页数

## 🔮 查看占卜记录

### 访问方式

点击左侧菜单"占卜记录"。

### 记录列表

#### 显示字段

| 字段 | 说明 |
|------|------|
| 时间 | 占卜创建时间 |
| 兑换码 | 使用的兑换码 |
| 问题 | 用户提出的问题（前50字） |
| 追问 | 追问次数 |
| 天使祝福 | 是否有天使祝福 |
| 操作 | 查看详情按钮 |

### 搜索记录

1. 在搜索框输入兑换码
2. 点击"搜索"按钮
3. 显示该兑换码的所有占卜记录

### 查看详情

1. 点击某条记录的"查看详情"按钮
2. 弹窗显示：
   - 完整问题
   - AI 解析内容（前200字）
   - 追问数量

**注意**：详情暂时以弹窗形式显示，未来可以优化为独立页面。

### 数据保留

- 占卜记录保留 **7 天**
- 超过 7 天的记录会自动删除
- 删除记录时，追问记录也会一并删除

## ❓ 常见问题

### 1. 忘记管理员密码怎么办？

**方法 1：重置密码（推荐）**
1. 访问 https://supabase.com/dashboard
2. 进入 `juzitaluo` 项目
3. 点击 **Authentication** → **Users**
4. 找到管理员邮箱，点击"..."菜单
5. 选择"Send Password Reset Email"或直接修改密码

**方法 2：创建新管理员**
1. 在 Supabase Auth 中创建新用户
2. 在 SQL Editor 中将该用户添加到 `admin_users` 表：
```sql
INSERT INTO admin_users (email, name, role)
VALUES ('新邮箱@example.com', '管理员名称', 'admin');
```

### 2. 生成的兑换码太多了，如何批量禁用？

目前不支持批量操作，需要逐个点击禁用。

**临时方案**：在 Supabase SQL Editor 中批量更新：
```sql
UPDATE redemption_codes 
SET status = 'disabled'
WHERE created_at > '2026-06-26'  -- 修改为实际日期
  AND status = 'active';
```

### 3. 兑换码用完了次数，能否增加次数？

可以在 Supabase SQL Editor 中手动修改：
```sql
UPDATE redemption_codes 
SET question_limit = question_limit + 3,  -- 增加3次
    question_used = 0                     -- 或重置已用次数
WHERE code = 'XXXX-XXXX-XXXX';           -- 替换为实际兑换码
```

### 4. 如何导出兑换码列表？

在 Supabase SQL Editor 中查询并导出：
```sql
SELECT code, question_limit, question_used, status, expires_at, note
FROM redemption_codes
ORDER BY created_at DESC;
```

点击查询结果右上角的"Download CSV"导出。

### 5. 登录后显示"认证失败"？

**可能原因**：
- Token 已过期
- Supabase 配置错误
- 管理员账号被禁用

**解决方法**：
1. 点击"退出"重新登录
2. 检查 Supabase `admin_users` 表中 `is_active` 是否为 `true`
3. 检查 Vercel 环境变量是否正确

### 6. 生成兑换码失败？

**可能原因**：
- 网络问题
- 参数错误
- 数据库权限问题

**解决方法**：
1. 检查输入参数是否在有效范围内
2. 查看浏览器控制台错误信息
3. 查看 Vercel Function Logs

### 7. 占卜记录看不到详细内容？

目前详情显示为简化版（弹窗），仅显示部分内容。

**查看完整内容**：
在 Supabase 中直接查询：
```sql
SELECT * FROM tarot_sessions 
WHERE id = '占卜记录ID';

SELECT * FROM tarot_followups 
WHERE session_id = '占卜记录ID';
```

## 💡 使用技巧

### 批量管理

1. **按批次备注**：生成兑换码时添加批次信息，如"2026-06第一批"
2. **使用搜索**：通过备注快速找到某批兑换码
3. **定期清理**：禁用已过期或不再使用的兑换码

### 数据分析

1. **查看统计趋势**：定期记录统计数据，对比增长
2. **分析使用率**：关注兑换码的实际使用情况
3. **追问率统计**：通过"平均追问数"了解用户活跃度

### 安全建议

1. **定期修改密码**：建议每3个月修改一次管理员密码
2. **不要分享登录信息**：管理员账号应该专人专用
3. **及时禁用废弃码**：不再使用的兑换码应及时禁用
