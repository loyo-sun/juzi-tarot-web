## 🎯 核心功能亮点

### 1. 雪花算法兑换码生成 ⭐⭐⭐⭐⭐

**特点**:
- 基于雪花算法，全局唯一
- 去除易混淆字符（O、I、L）
- 随机打乱，无规律可循
- 格式：`XXXX-XXXX-XXXX`（12位）
- 支持批量生成（1-100个）

**实现**:
```javascript
// 雪花算法生成 → Base33编码 → 随机盐值 → 字符打乱 → 格式化
generateSingleCode() → XXXX-XXXX-XXXX
```

### 2. 完整的权限系统 ⭐⭐⭐⭐

**前端用户**:
- 仅使用兑换码认证
- 无需注册/登录
- 兑换码即身份凭证

**管理员**:
- Supabase Auth 邮箱密码登录
- JWT Token 验证
- 权限分级（admin / super_admin）

### 3. 数据安全 ⭐⭐⭐⭐⭐

**Row Level Security (RLS)**:
- 所有表启用 RLS
- 精细化的访问控制策略
- 匿名用户只能访问自己的数据

**原子性操作**:
- 使用数据库 RPC 函数
- 防止并发导致的次数扣减问题
- 事务级别的数据一致性

### 4. 自动化管理 ⭐⭐⭐⭐

**7天自动清理**:
- 占卜记录自动过期
- 追问记录级联删除
- 定时函数支持

**自动状态更新**:
- 过期兑换码自动标记
- 使用时间自动记录
- 统计数据实时计算
